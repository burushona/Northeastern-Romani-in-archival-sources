# Checks on the published text

The index was converted automatically from the PDF of the book. The places below are worth checking.

## Forms that could not be matched with a source

| Entry | Problem |
|---|---|
| mangél | after *манге́ла (наст. ед. 2 возв. …* a bracket is opened and never closed, so «Добр. 1908» ends up inside the brackets: *мангэ́ла, манге́ла* have no source in the data |
| kedél, s- | *скедэ́лпэ «скорчиться» (прош. 3 ед. …*: a bracket is not closed before the citation |

## Other

* *dlúgo¹*: the citation «Патк. 1900» is set in italics; this is corrected during conversion.
* The list of sources (p. 8) gives Bardanes's list as “Источник 2”, but in the book it is Источник 1 (Источник 2 is Rüdiger). The data link it to Источник 1.
* The list of sources cites Grigor'ev's material as [Böhtlingk 1852, 1854], but the bibliography has *Boehtlingk 1853* (and Böhtlingk 1854). `sources.bib` uses the bibliography entries.
