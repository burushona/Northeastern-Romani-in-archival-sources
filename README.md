# North-Eastern Romani in 18th–19th-century sources: word index (CLDF)

This repository holds the word index (Словоуказатель) of

> Кожанов К. А. *Цыганский язык в источниках XVIII–XIX вв. (из архивов России и Литвы).* Санкт-Петербург: Маматов, 2025. ISBN 978-5-91076-297-2.

as a [CLDF](https://cldf.clld.org) dataset, together with a search page that runs in the browser (GitHub Pages) and needs no server.

The index lists every word form found in North-Eastern Romani sources from the first records in the late 18th century to the early 20th century. Each headword is a generalised North-Eastern form. Under it, the forms are cited as they are written in each source, in chronological order.

## Contents

| Path | What it is |
|---|---|
| `cldf/` | the CLDF dataset (Dictionary module) |
| `docs/` | the search page (`index.html` + `data.json`), served by GitHub Pages |
| `scripts/` | conversion scripts: PDF of the book → CLDF → search page |
| `build.sh` | runs the whole conversion |

### The CLDF tables

* `entries.csv`: 1,597 headwords plus 1,144 derived forms and prefixed verbs (уменьш., прич., нар., сравн., порядк., деепр., отр., prefixes), linked to their main entry through `Main_Entry_ID`. It also holds the paradigm forms, grammatical labels, the notes on distribution and derivation, the etymology and the cross-references.
* `senses.csv`: the meanings of the headwords in Russian (`Description`) with a transliteration (`Description_Latin`). Numbered meanings are separate rows.
* `attestations.csv`: 8,598 attested forms, one row per form and source. Columns:
  * `Form`: the form as written in the source
  * `Form_Latin`: its transliteration
  * `Source`: BibTeX key(s)
  * `Source_Abbreviation`: the citation as printed in the book
  * `Editor_Note`: the author's labels before the form (мн., пов. 2 ед., субст. ж. …)
  * `Source_Annotation`: what the source gives after the form (bracketed inflected forms, «translations», + additional meanings)
  * `Source_Glosses`: the «» translations on their own
  * `Sense_Numbers`: the (1), (2) markers
  * `Uncertain`: forms marked (?)
* `sources.bib`: the book itself, one entry per source and year as abbreviated in the book (with the description from the book's list of sources and the full reference of the publication), the archival collections and the electronic databases.

## Transliteration

**Romani forms** (`Form_Latin`): Cyrillic is converted letter by letter using Romanist conventions. Latin-script forms (Bacmeister, Narbutt, Glinski …) are left unchanged.

* ж ž, х x, ц c, ч č, ш š, щ šč, ы y, э e, й j, і i, ѣ ě, ў ŭ
* тх th, кх kh, пх ph, чх čh, дж dž
* я ю ё е after a consonant: ʼa ʼu ʼo ʼe. Elsewhere: ja ju jo je. After ч ш ж щ: plain a u o e.
* ь: ʼ (U+02BC); ъ is dropped
* In Patkanov, Latin g stands for dž and h marks aspiration.
* Stress marks and the other diacritics of the source are kept.

**Russian meanings and glosses** (`*_Latin`): scholarly transliteration.

* ж ž, х x, ц c, ч č, ш š, щ šč
* ы y, э è, ю ju, я ja, ё ë, й j
* ь ʹ, ъ ʺ, ѣ ě

The transliteration is generated by `scripts/translit.py`; changing the rules there and re-running `build.sh` regenerates every column.

## Search page

`docs/index.html` loads `docs/data.json` and searches:

* headwords
* attested forms (original and transliterated)
* meanings and glosses
* etymologies

Search ignores diacritics and accents by default, and you can filter by source or by initial letter. To publish it, go to **Settings → Pages** in the repository and choose *Deploy from a branch*, branch `main`, folder `/docs`. The page then appears at `https://<user>.github.io/<repository>/`.

`preview.html` is the same page with the data built in, so it opens straight from disk without a web server.

## Rebuilding

The data are extracted from the PDF of the published book (word index on pp. 447–581). Fonts mark the structure: bold for headwords, italic for forms from the sources.

```sh
pip install pdfplumber
sh build.sh path/to/book.pdf
```

`scripts/sources.json` (the book's list of sources, pp. 8–9, with references from the bibliography), `scripts/archives.txt` and `scripts/hyphenated_words.txt` (words with a real hyphen, used to join lines) are kept in the repository, so only the PDF is needed.

To check the dataset against the CLDF standard:

```sh
pip install pycldf
cldf validate cldf/Dictionary-metadata.json
```
