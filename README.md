# North-Eastern Romani in 18th–19th-century sources: word index (CLDF)

This repository holds the word index (Словоуказатель) of

> Кожанов К. А. *Цыганский язык в источниках XVIII–XIX вв. (из архивов России и Литвы).* Санкт-Петербург: Маматов, 2025. ISBN 978-5-91076-297-2.

as a [CLDF](https://cldf.clld.org) dataset, together with a search page that runs in the browser (GitHub Pages) and needs no server.

The index lists every word form found in North-Eastern Romani sources from the first records in the late 18th century to the early 20th century. Each headword is a generalised North-Eastern form. Under it, the forms are cited as they are written in each source, in chronological order.

## Contents

| Path | What it is |
|---|---|
| `cldf/` | the CLDF dataset (Dictionary module) |
| `docs/` | the search page (`index.html` + `data.json`), served by GitHub Pages |
| `docs/sources/` | the list of sources with full references, and the texts of the sources as edited in the book (part 2, pp. 94–446), one page per source |
| `scripts/` | conversion scripts: PDF of the book → CLDF → search page |
| `build.sh` | runs the whole conversion |

### The CLDF tables

* `entries.csv`: 1,597 headwords plus 1,144 derived forms and prefixed verbs (уменьш., прич., нар., сравн., порядк., деепр., отр., prefixes), linked to their main entry through `Main_Entry_ID`. Each entry has:
  * the meaning in Russian (`Meaning`) and in English (`Meaning_English`)
  * the paradigm forms and grammatical labels
  * the notes on distribution
  * the base of derivation (← in the book: `Derived_From`, linked to its entry in `Derived_From_ID`)
  * the composition (`Composition`, `Composition_IDs`)
  * the cross-references (`See_Also`, `See_Also_IDs`)
  * the etymology
* `senses.csv`: the meanings, one row per numbered sense, in Russian (`Description`) and English (`Description_English`).
* `attestations.csv`: 8,598 attested forms, one row per form and source. Columns:
  * `Form`: the form as written in the source
  * `Form_Latin`: a Latin transliteration of Cyrillic forms
  * `Source`: BibTeX key(s)
  * `Source_Abbreviation`: the citation as printed in the book
  * `Edition`, `Edition_Page`: for sources whose text is edited in the book, which text it is and the page where the form occurs
  * `Editor_Note`: the author's labels before the form (мн., пов. 2 ед., субст. ж. …)
  * `Source_Annotation`: what the source gives after the form (bracketed inflected forms, «translations», + additional meanings)
  * `Source_Glosses`: the «» translations on their own
  * `Sense_Numbers`: the (1), (2) markers
  * `Uncertain`: forms marked (?)
* `sources.bib`: the book itself, one entry per source and year as abbreviated in the book (with the description from the book's list of sources and the full reference of the publication), the archival collections and the electronic databases.

## English meanings and transliteration

The English meanings (`Meaning_English`, `Description_English`) are translations of the Russian meanings of the book. They were drafted with Claude (Anthropic) and are listed in `scripts/meanings_en.json` (Russian → English), so they can be corrected there.

`Form_Latin` is a letter-by-letter transliteration of the Cyrillic forms with Romanist conventions. It is generated by `scripts/translit.py` and is hidden on the search page by default.

## Search page

`docs/index.html` loads `docs/data.json` and searches:

* headwords
* attested forms
* meanings and glosses, in Russian and English
* etymologies

Search ignores diacritics and accents by default, and you can filter by source or by initial letter.

* Bases of derivation (←), derivatives, compounds and “see also” are links to the entries.
* Clicking a source year opens its description and full reference.
* “p. …” opens the text of the source in the book at the page where the form occurs, with the form highlighted.

To publish it, go to **Settings → Pages** in the repository and choose *Deploy from a branch*, branch `main`, folder `/docs`.

## Rebuilding

The data are extracted from the PDF of the published book (word index on pp. 447–581). Fonts mark the structure: bold for headwords, italic for forms from the sources.

```sh
pip install pdfplumber
sh build.sh path/to/book.pdf
```

The pages of a form in the source texts are found automatically by searching the form in the text of each source (3,841 of 3,967 forms from these sources are found).

`scripts/sources.json` (the book's list of sources, pp. 8–9, with references from the bibliography), `scripts/meanings_en.json`, `scripts/archives.txt` and `scripts/hyphenated_words.txt` (words with a real hyphen, used to join lines) are kept in the repository, so only the PDF is needed.

To check the dataset against the CLDF standard:

```sh
pip install pycldf
cldf validate cldf/Dictionary-metadata.json
```
